## 📌 Lab summaries

### IAM Access Governance Lab

Built a foundational IAM lab in Microsoft Entra ID covering users, groups, RBAC, MFA, Conditional Access, joiner/mover/leaver workflows, privileged access concepts, and access review simulation.

### IAM Access Request and Approval Lab

Documented a request-based access workflow using access packages, approvals, least-privilege decisions, access verification, denial notes, and ticket closure.

### IAM User Access Troubleshooting and Lifecycle Support Lab

Worked through IAM support scenarios covering MFA validation, new hire access, mover cleanup, leaver cleanup, audit access validation, access matrix review, and ticket documentation.

### SailPoint ISC Governance Review Lab

Created a public-safe SailPoint ISC governance review lab using fictional scenarios, sanitized findings, short analyst notes, and recreated Mermaid diagrams.

The project covers identity profiles, lifecycle states, access models, certifications, Search, Identity Graph, least privilege, and joiner/mover/leaver governance.

This public version does not include screenshots, tenant details, course material, configuration steps, IDs, URLs, secrets, tokens, API keys, or internal information.
